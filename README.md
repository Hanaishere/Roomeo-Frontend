# Roomeo

Roomeo is a full-stack student accommodation platform built to help students discover dorms, PGs, and shared housing in a simpler and more reliable way. The platform focuses on providing a smooth and modern experience for students moving to new cities through secure authentication, responsive listings, and cloud deployment support.

---

## Features

- User registration and login using JWT authentication
- Browse dorm and PG listings
- Responsive React frontend
- REST API integration
- Secure backend using Spring Boot and Spring Security
- MySQL database integration
- Cloud deployment using Render and Vercel
